# BoostProjectLJ4Hackaton6 – Niet-zo-single-feestje

Hackaton 6: een slimme hartketting voor het Valentijnsfeest **Smèrrig** in Poppodium 013.
Het prototype bouwen we in [Wokwi](https://wokwi.com/) (ESP32).

## Inhoud
- [`docs/ontwerpdocument.md`](docs/ontwerpdocument.md): concept, keuzes, prototypeontwerp (pinplan, toestanden, MQTT)
- [`docs/ontwerpdocument.docx`](docs/ontwerpdocument.docx): Word-versie voor de inlevering
- [`docs/planning.md`](docs/planning.md): sprints, testplan en inleverlijst
- [`wokwi/hart/`](wokwi/hart/): Wokwi-prototype (sketch, `diagram.json`, `libraries.txt`) + instructies

## Word-versie opnieuw maken
Het ontwerpdocument wordt bijgehouden in Markdown. De `.docx` maak je opnieuw met:
```bash
cd tools && npm install && npm run docx
```
